Разметка B06

Я —
Оценивайте пользу материала для этого профиля по публичной карточке, как в docs/labeling.md. Источник карточки, позиция и объяснение системы скрыты.
2 прямо полезно: сам закрывает следующий шаг по задаче, подходит по стадии, уровню и времени.
1 частично: по теме, но слишком общее, справочное, вводное вместо практического, покрывает часть задачи или не по времени.
0 не подходит: другая задача, чужая отрасль, недоступный уровень, уже пройдено.
? нельзя оценить по публичным данным — обязательно напишите причину. Материал явно о другой задаче — это 0, а не «?». Ответы сохраняются в этом браузере; итоговый файл скачайте кнопкой внизу.
Выберите свой код A или B вверху — появятся ваши профили.

При нескольких задачах достаточно прямой пользы по одной явно заявленной задаче, если соблюдены стадия, уровень и бюджет времени. Курс 210 минут при бюджете 60 минут без отдельного инструмента — 1. Вводный термин по нужной сфере без практического решения — 1; посторонняя тема — 0.
