# Матрица требований

Источник строк F и S — PDF кейса трека 1 (см. [контекст](CONTEXT.md)). O — необязательные возможности, U — требования команды к удобству. Состояние на 13 ноября 2026 года: реализация не начата, ни одно требование не подтверждено. Наличие строки не доказывает прохождение.

При подтверждении указывать дату, commit SHA, среду, входы, результат и путь к доказательству.
