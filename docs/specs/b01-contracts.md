# Контракты B01

Уточнение типов раздела 5.3 [ТЗ](2026-11-13-recommender-tz.md). Статус: технически приняты 14 ноября 2026 года на `f688570` после проверки реализации, независимого ревью и зелёного CI Windows/Ubuntu. Используются в зависимых задачах; слияние [PR #4](https://github.com/ib1te1/alfa-hack-and-change/pull/4) выполняется отдельно.

Общие модели и протокол находятся в `alfarec.recsys.contracts`, схема HTTP-запроса — в `alfarec.api.schemas`. Доменный слой зависит от Pydantic, но не от FastAPI. Входы отклоняют неизвестные поля; числовые оценки не принимают NaN и бесконечности. URL допускают только HTTP/HTTPS; соответствие реальному адресу платформы проверяется при сборке каталога.

| Поле | Представление |
|---|---|
| `Profile.stage` | `idea`, `launch`, `operating`, `growth` или `null` |
| `Profile.experience` | `beginner`, `intermediate`, `advanced` или `null` |
| `Profile.time_budget` | `quick` (5 минут), `hour` (час), `course` (готов к курсу) или `null` |
| `Profile.industries`, `Profile.tasks` | Списки строк таксономии B03; отсутствующее поле и `null` превращаются в пустой список. До B03 фиксированного перечня кодов задач и сфер нет |
| `Profile.free_text` | Необязательная строка до 2000 символов |
| `Event.ts`, `Item.published_at` | ISO 8601 со смещением часового пояса. Время события обязательно; дата материала может отсутствовать |
| `Event.type` | `view`, `complete`, `save`, `enroll`, `rate`, `known`, `dislike` |
| `Event.value` | Необязательное конечное число; для `rate` обязательна целая оценка 1–5 |
| `Reason.code` | Закрытый перечень `ReasonCode` из раздела 5.3 ТЗ |
| `Reason.weight`, `Recommendation.score` | Конечные числа. Отрицательный вклад допустим; шкала суммарного score не ограничивается диапазоном 0–1 |
| `Reason.params` | Словарь строковых ключей и скалярных значений: строка, конечное число, bool, null. Ключи шаблонов объяснений (B08): `task_match` — `task`, `industry_match` — `industry`, `stage_fit` — `stage` (код таксономии или готовое название), `continues_history` — `title`, `short_format` — `minutes`, `material_format` — `format` (факт о формате материала: добавляется в `explain`, когда иных причин меньше двух; ранжирование его не создаёт, вес 0). Без нужного ключа причина формулируется общими словами: `short_format` без `minutes` (у калькуляторов время не записано) — «Короткий формат: ответ сразу» |
| `Reason.text` | Необязательный текст причины. Ранжирование его не заполняет: текст добавляет `alfarec.recsys.explain` на выходе API. Добавлено в B08, требует согласования участников |
| `RecommendationResponse.route_note` | Необязательная строка до 300 символов о порядке шагов маршрута; заполняется в `explain`, если в маршруте не меньше двух ролей. Добавлено в B08 |
| `NextStep.kind` | `read`, `download`, `calculate`, `start_course`, `watch`, `listen`, `subscribe`, `purchase` |
| `Clarification.options` | 2–4 текстовых варианта; отправка выбранного варианта реализуется в B07 |
| `RecommendationRequest.limit` | Целое 1–50, по умолчанию 10; максимальный размер списка `more`. Маршрут и короткая подборка ограничиваются отдельно в B05 |

Все поля профиля необязательны. `Item` — только публичная карточка: метаданные и описание до 300 символов. Поля `index_text`, текст урока и другие произвольные поля в неё не входят. Проверка схемы сама по себе не подтверждает, что описание не содержит закрытый текст: источник и очистка данных проверяются в B02/B08.

`Recommender.recommend(profile, history, mode="ours", limit=10)` возвращает `RecommendationResponse`. История — последовательность `Event`; адаптер API должен передавать историю только нужного пользователя. `user_id` относится к HTTP-запросу, а не к предпочтениям профиля. Формирование маршрута, учёт истории, квоты и объяснения реализуются в B05/B08.

Заглушка `StubRecommender(catalog)` принимает последовательность `Item`, проверяет уникальность ID и сохраняет отдельную копию. Выборка воспроизводима по SHA-256 ID и не зависит от порядка строк или глобального random. Заглушка заполняет только `more`, возвращает нулевые score, пустые reasons и ссылку «Открыть материал». Она не учитывает профиль и историю и не является бейзлайном; значение `mode` только передаётся в ответ. Входные данные и ранее выданные ответы не изменяются при следующем вызове.

Пустой каталог даёт пустую выдачу. Ни материалы, ни объяснения не выдумываются. Через HTTP заглушка пока не опубликована: B01 предоставляет `/api/health`, `/docs` и `/openapi.json`.

Открытые вопросы следующих этапов: поля для «плана на неделю» и продолжения курса; граница обновления предпочтений между B05 и E04. Их отсутствие не подменяется новыми неоговорёнными полями в B01.
