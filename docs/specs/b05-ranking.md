# B05: ранжирование

Реализация [карточки B05](../tasks/CORE.md) по разделам 6.3–6.6 [ТЗ](2026-11-13-recommender-tz.md). Код — `alfarec/recsys/ranking.py`, словарь понимания текста — `alfarec/recsys/intent.yaml`, тесты — `retrieval_tests/test_ranking.py`. `load_ranker()` строит `Ranker` по закоммиченному каталогу и резервному TF-IDF индексу B04 с полной проверкой хешей; класс реализует протокол `Recommender`.

## Что используется сейчас

ML-меток и эмбеддингов B04 ещё нет, поэтому работает резервный вариант:

- **Семантическая близость** — TF-IDF индекс B04 по названию и описанию (`text_source: metadata`). Запрос строится из свободного текста, названий и описаний задач профиля и названий сфер.
- **Задачи материала** — по исходной разметке: тег задачи — 1.0, рубрика статьи — 0.8, тема — 0.5. Широкие темы связаны с несколькими задачами, поэтому это слабый сигнал ([labeling.md](../labeling.md)).
- **Стадии** — по меткам «Старт бизнеса», «Первые шаги», «Регистрация бизнеса», «Без опыта» (идея, запуск), «Идеи для бизнеса», «Выбор ниши» (идея) и «Развитие бизнеса» (работа, рост). Без меток — нейтральные 0.5.
- **Уровень** — глоссарий и названия вида «с нуля», «азбука», «что такое» — начальный; «С опытом», LBO, «масштаб», «стратегия» — продвинутый; остальное — средний.
- **Свободный текст** — явный словарь для 14 задач и 4 стадий, а также границ каталога: иностранное право, индивидуальный прогноз, темы не про бизнес. Признак — регулярное выражение от начала слова с явной границей конца там, где короткая основа даёт ложные совпадения («ип» и «ипотека», «бот» и «ботаник», «банк» и «банкет»). Граница «иностранное право» срабатывает только вместе с регистрацией, законами или налогами и не срабатывает для ВЭД. При равенстве стадий стадия не выставляется. Лексическая близость к описаниям задач не отделяла запросы вне каталога, поэтому выбраны прозрачные правила; отрицательные примеры закреплены тестами.

Когда B04 передаст `item_labels.parquet` и векторы, `ItemFacts` и признак `semantic` заменяются без изменения интерфейса.

## Скоринг

Сумма `вес × признак`, признаки в [0, 1] (у `history` и `offer` допустим отрицательный вклад). Начальные веса заданы вручную в `DEFAULT_WEIGHTS` и подбираются в B06:

| Признак | Вес | Значение |
|---|---|---|
| `semantic` | 1.2 | Близость к запросу, нормированная на лучший результат |
| `task` | 2.0 | Сила связи материала с задачей профиля |
| `stage` | 0.6 | Матрица совместимости стадий из ТЗ |
| `level` | 0.6 | Совместимость уровня материала и опыта; продвинутое для новичка — 0.1 |
| `industry` | 0.8 | 1 — та же сфера, 0.6 — для всех, 0 — чужая |
| `format` | 0.5 | Соответствие бюджету времени |
| `history` | 1.0 | Близость к положительным событиям, минус близость к отрицательным |
| `quality` | 0.4 | Сглаженная доля завершений и оценка |
| `popularity` | 0.3 | Логарифм популярности; при пустом профиле вес ×4 |
| `fresh` | 0.2 | Публикация за последний год по темам изменений законов |
| `offer` | 0.3 | Платное уместно, если нужен курс или бесплатное по теме уже пройдено; иначе −1 |

Каждый положительный вклад превращается в код причины (`task_match`, `stage_fit`, `beginner_friendly`, `industry_match`, `continues_history`, `popular_with_similar`, `short_format`, `fresh`, `next_level`, `deep_dive_course`) с параметрами для шаблонов B08.

## Порядок ответа

1. **Границы каталога.** Если задачи в профиле не выбраны, совпадение с границей даёт уточнение с вариантами и общую подборку, маршрута нет. Выбранные задачи важнее границы.
2. **Холодный старт** (пустой профиль и нет положительных событий истории): стартовый набор — проверенный курс для начинающих, налоговый калькулятор, шаблон для старта, свежие изменения законов, статьи самых частых тем. В `route` — «План на неделю»: пять коротких материалов до 10 минут по теме старта бизнеса, по одному на день.
3. **Низкая уверенность** — свободный текст без признаков задач, либо несколько равных задач при слабой близости самого текста пользователя к каталогу: уточнение с 2–4 вариантами по главным задачам среди кандидатов.
4. **Кандидаты:** близкие по индексу (до 300), материалы задач профиля, соседи материалов из истории, курсы с записями. Пройденное, «Уже знаю» и «Не то» исключаются.
5. **Маршрут и «Быстро»** выбираются из отсортированных кандидатов, затем остаток проходит **переранжирование**: MMR (λ = 0.75) по сходству задач, темы и формата; в первых пяти карточках «Ещё по теме» не больше одного платного, не больше двух одной темы, не меньше двух форматов. Если квоты несовместимы, сохраняется лимит платного.
6. **Маршрут** (шаг 5): до двух шагов «понять», один «сделать», один «углубиться», только из материалов с совпадением задачи; порядок — роль, затем уровень. Если набирается меньше трёх шагов, маршрута нет.
7. **«Быстро, за 5 минут»** — до четырёх коротких ответов и инструментов. **«Продолжить курс»** — начатый и не завершённый курс ставится первым в `more` с кнопкой «Продолжить курс».

Причины: каждый положительный вклад признака даёт код; `task_match` ставится только при связи материала с задачей профиля, `stage_fit` — только при метке стадии материала. Если причин меньше трёх, список дополняется фактами о материале, не противоречащими профилю: популярность, «для начинающих» (если опыт не выше начального), длительность или формат инструмента, свежесть, бесплатный курс.

История: веса событий из раздела 6.4 с затуханием (период полураспада 30 дней); «Уже знаю» исключает материал и поднимает уровень на ступень, неизвестный опыт считается начальным (причина `next_level` — только у материалов выше начального уровня); пустые задачи профиля достраиваются по истории. `profile_used` возвращает понятые задачи, стадию и уровень. Время отсчитывается от самой свежей публикации каталога, поэтому ответ детерминирован.

## Проверено

- Все 36 профилей: ответ быстрее 1 секунды на CPU (локально максимум около 0,07 с), повторный вызов даёт тот же ответ.
- Сетка 14 задач × 4 бюджета × 3 уровня: квоты платного и форматов в первых пяти карточках, причина у каждой карточки.
- A02: маршрут из 3–5 шагов разных форматов по ролям, у каждого шага причина `task_match`.
- A03: пройденное исключено, начатый курс первым с причиной `continues_history`, выдача отличается от выдачи без истории.
- A04: стартовый набор из 6–8 материалов трёх и более форматов и план на неделю.
- A05: пять профилей «уточнить» получают уточнение, восемь профилей со свободным текстом — задачи.
- «Уже знаю» и «Не то»; холодный старт при истории только из «Уже знаю», «Не то» или неизвестных ID; приоритет задач профиля над границей; бейзлайн по разделу 6.6.

## Ограничения

- Метрики качества против бейзлайна не измерены — это B06; веса ручные.
- TF-IDF по метаданным — лексический сигнал; полный текст и эмбеддинги появятся после передачи входов B04.
- Словарь понимания текста покрывает частые формулировки; незнакомый запрос без признаков задач честно уходит в уточнение.
- В API `Ranker` обслуживает `mode=ours`, бейзлайн — единственная реализация `TopicBaseline`; NumPy, SciPy и scikit-learn — runtime-зависимости. При недоступном или устаревшем индексе сервис переходит на бейзлайн и сообщает об этом в `/api/health`.
