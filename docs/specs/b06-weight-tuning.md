# B06: воспроизводимый подбор весов без утечки holdout

Продолжение принятого протокола: 22 профиля tune, 14 holdout. Публичные
контракты API не меняются. Исходные ответы A/B сохраняются побайтно; отдельные
подтверждённые копии меняют только independent согласно подтверждению участников.
Ответы проверяются против исходного пакета, а не пакета с подменённым хешем.

## Подбор

Фиксированная небольшая сетка: начальные веса и изменение каждого содержательного
признака в 0,5 и 1,5 раза. Вес переходов sequence уже выбран отдельным протоколом
и не настраивается повторно. Все кандидаты оцениваются только на tune.
Цель — средний nDCG@10; при равенстве сохраняем начальные веса или минимальное
число изменений. Не адаптируем сетку после просмотра holdout.

Истории профилей фиксируются по исходной разметке до сравнения вариантов:
ML-предсказания не должны менять сам сценарий при сравнении кодировщиков.
Набор для каждой метрики — route, затем more, уникальный top-10, как прежде.

Неоценённые новые карточки не считаются нерелевантными и не удаляются из рангов.
При неполном покрытии любого кандидата tune подбор блокируется, сохраняются
точные недостающие пары и самодостаточная слепая форма. Гипотезы с неполной
разметкой не отбираются по более удобному покрытию. После выбора проверяется
покрытие единственного holdout-списка; при нехватке оценок итог не объявляется.

При полном покрытии сохраняются `artifacts/weights.json`, фиксированные списки,
метрики tune и holdout и хеши данных/разметки/ML/весов. Один и тот же файл весов
читает API через B05. Никаких фиктивных оценок и заявлений об улучшении.

## Исторические ответы

Отчёт исходного пакета допустим как отдельное историческое измерение. Его
нельзя выдавать за проверку нового dense-ранкера. Перенос оценок между пакетами
допускается только при совпадении видимого профиля, истории, карточки и версии
инструкции; иначе нужны новые оценки либо явное решение по применимости
обновлённой инструкции. Исходники и решения хранятся отдельно.

## Приёмка

Тесты отсутствия утечки holdout, блокировки неполного покрытия, детерминизма,
валидации входов и фактического применения сохранённых весов. Пересчитанный
отчёт по переданным исходным выгрузкам. Независимое ревью и CI. Если данные
не позволяют закрыть всю B06, карточка сохраняет точный остаток и форму.
