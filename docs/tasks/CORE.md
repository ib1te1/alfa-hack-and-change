## B02. Каталог из дампа

- **Владелец:** А.
- **Исполнитель:** `enioZz95`, ветка `feature/b02-catalog`, [PR #7](https://github.com/ib1te1/alfa-hack-and-change/pull/7); исправление текстов — [PR #13](https://github.com/ib1te1/alfa-hack-and-change/pull/13).

Повторная сборка даёт побайтно тот же файл. [Отчёт о покрытии таксономии](../../reports/taxonomy_coverage.md) воспроизводится `python -m alfarec.pipeline.coverage`; связи задач найдены в каталоге, статус таксономии — `audited`. Решения по данным — ниже в «Принятых правилах».
- **Вход:** дамп в `data/alfa_course_hackathon.backup`, [сводка по данным](../hackathon/DATA.md), раздел 5.1 ТЗ.
- **Работа:** `python -m alfarec.pipeline.build_catalog` читает дамп через `pgdumplib` без PostgreSQL; собирает опубликованные неудалённые статьи, документы, курсы, вебинары, подкасты, глоссарий, калькуляторы; очищает HTML; разбирает длительность; определяет `access` и цену (`Courses.Cost = NULL` — бесплатно, курсы «По подписке» — подписка «Курс+»); нормализует темы, теги и отрасли (латинские двойники, удалённые записи); собирает URL из слагов и `PLATFORM_BASE_URL`; считает популярность, долю завершений, средние оценки. Пишет `artifacts/catalog.parquet` без полного текста и `data/processed/index_text.parquet` с текстом для эмбеддингов. Для платных и подписочных материалов в текст индекса идут только публичные описания лендинга, без уроков.
- **Приёмка:** ~1500 материалов, число по типам совпадает с [DATA.md](../hackathon/DATA.md); нет пустых `title` и `url`; тест: ни одна строка артефактов не содержит фрагментов `LessonEmbedItems`; повторный запуск даёт тот же файл.
- **Передача:** сообщить Гланде путь и схему, как только v1 готов, — это разблокирует критический путь.
- **Передача в B04 подготовлена:** `python -m alfarec.pipeline.export_handoff` пишет в `data/handoff/` (вне git) `index_text.parquet`, `editorial_pairs.parquet` (3880 редакторских связей из `RecommendedItems` и `DocumentBindings`), `course_enrolments.parquet` (10 032 записи на курсы, ID пользователей заменены порядковыми псевдонимами) и `manifest.json`. Версии, хеши и обоснование публичности полей — в [отчёте передачи](../../reports/b02_handoff.md). Хеши относятся к каталогу с исправлением смешанных букв ([PR #13](https://github.com/ib1te1/alfa-hack-and-change/pull/13)); индекс и калибровку, собранные на `4a7922e`, после слияния нужно пересобрать. Физическая передача папки получателю выполняется участниками вне репозитория.
- **Для B04:** `alfarec.recsys.catalog.load_catalog()` возвращает список `Item` из `artifacts/catalog.parquet` (поля раздела 5.1 ТЗ без `index_text`). Текст для эмбеддингов — `data/processed/index_text.parquet` с колонками `item_id`, `item_type`, `access`, `index_text`; его создаёт `python -m alfarec.pipeline.build_catalog` из дампа. Медиана текста ~4 тыс. символов, тело открытых материалов обрезано до 4000 символов; у платных и подписочных — только публичный лендинг. `alfarec.pipeline.dump_reader.read_tables(path, names)` читает любые таблицы дампа, например `RecommendedItems` и `DocumentBindings` для проверки моделей.
- **Принятые правила:**
  - Опубликованный материал — статус «Опубликовано» и `IsDeleted = false`; калькулятор — страница `CalculatorPages`, на неё ссылаются оценки.
  - Доступ: курс с `Cost` или типом «Платный» — `paid` с ценой курса; курс из `CourseSubscriptions` или типа «По подписке», подкаст из `PodcastSubscriptions` и статья с `IsClosed` — `subscription` с ценой основного тарифа «Курс+» со скидкой (990 ₽ в месяц). Остальное — `free`, включая статьи `IsPublic = false`: это скрытые из ленты, но открытые страницы.
  - URL: `PLATFORM_BASE_URL` (по умолчанию `https://kurs.alfabank.ru` — этот адрес и пути используют ссылки внутри статей дампа) + `/articles`, `/documents`, `/courses`, `/podcasts`, `/vocabulary`, `/calculators`, `/webinars` + слаг. Путь вебинаров в ссылках дампа не встречается и не подтверждён.
  - Текст индекса: заголовок, описание, подзаголовки, публичные тексты лендинга курса и деталей подкаста, до 4000 символов тела открытых статей, документов, глоссария и калькуляторов. У статей с `IsPublic = false` тело не берётся: их публичность не подтверждена. Уроки не читаются вовсе; тело статей «Курс+» не берётся.
  - Популярность и доля завершений — по неудалённым записям `CourseUserBindings`; оценка курса — среднее оценок его уроков; у калькуляторов популярность — число оценок, так как журнала посещений нет.
  - Проверка утечки уроков на реальном дампе считает утечкой строку урока длиной от 40 символов, которой нет в открытых статьях: 9 строк уроков дословно повторяют открытые статьи (ставки НДФЛ, перечни сертификации) и утечкой не являются.
