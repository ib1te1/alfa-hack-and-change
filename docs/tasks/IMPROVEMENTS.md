## E01. Перефразирование объяснений языковой моделью

Необязательный режим, включаемый переменной окружения: локальная или внешняя модель через HTTP API получает только коды причин, название и публичное описание материала — без профиля пользователя и закрытых текстов. Без переменной всё работает на шаблонах. Приёмка: в README указаны сервис, модель и переменная ключа; ответ не содержит фактов вне входа.

## E02. Learning-to-rank вместо ручных весов

LightGBM или CatBoost с целевой функцией ранжирования на оценках релевантности и синтетической обратной связи. Принимается, только если на отложенных профилях nDCG@10 выше линейной модели, а объяснения сохраняются через вклад признаков.

## E03. Публичный стенд для ссылки на первом слайде

Развернуть тот же образ на бесплатном или собственном хостинге с доступом по ссылке. Обязательное условие: на стенде нет дампа, полных текстов и платного содержания; согласовать с организаторами допустимость публикации каталога. Работать должен во время проверки.

## E04. Онлайн-обновление профиля по обратной связи

«Уже знаю» и «Не то» обновляют предпочтения по задачам, уровню и формату в рамках сессии, а не только исключают материал. Приёмка: три последовательных «Не то» по одной теме уводят выдачу от неё; поведение видно в объяснениях.

## E05. Дообучение модели эмбеддингов

Контрастивное дообучение на парах из редакторских подборок с отложенной частью для проверки. Принимается, только если Recall@10 на отложенной части растёт заметно, а веса помещаются в образ.
