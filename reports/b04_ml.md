## Выбор и ограничения

Выбрана multilingual-e5-small, ревизия `614241f622f53c4eeff9890bdc4f31cfecc418b3`: лучший tune nDCG среди нейросетевых кандидатов в пределах целевых 500 МБ и 150 мс. USER — 502,6 МБ (слегка выше цели), E5-base — 1134,5 МБ. Полный TF-IDF немного сильнее на tune: 0,1329 против 0,1303; превосходство нейросети не заявляется. На holdout измерения опубликованы описательно, после автоматического правила выбора по tune/размеру; по holdout модель и пороги не менялись. Эта небольшая редакторская выборка не доказывает рост пользовательской релевантности или конверсии. Резерв сервиса остаётся существующим TF-IDF по метаданным; TF-IDF в таблице построен по полному разрешённому index_text, это разные текстовые источники.

## Метки и контроль

Локальная Qwen2.5-7B-Instruct, ревизия `a09a35458c702b33eeacc393d103063234e8bc28`, Transformers + bitsandbytes NF4, полностью на CUDA. Все 1497 ответов — валидные стадии/уровень; пик VRAM 6 443 519 488 байта. Первый материал проверен отдельно (лимит 100 токенов, batch1), остальные — batch8 и 80 токенов. Системная инструкция и публичные карточки одинаковы; хеши в [манифесте меток](b04/labels_manifest.json). Сырые LLM-ответы без текстов находятся локально в data/b04/labels/llm.json; их хеш и сводка сохранены в b04/llm_run.json.

Классификаторы задач и сфер: LogisticRegression C=1, balanced, seed 20261115; только материалы с точными исходными метками, минимум 8 положительных/отрицательных, threshold 0,8. Пустая исходная разметка не считается отрицательным примером. Для задач используются raw_tags/article_subjects, не широкие Topics. Низкая уверенность означает abstain. Ручные 120 материалов не обучают классификаторы.

Сравнение с [реальными человеческими ответами](label_check/b04-label-check.json), подтверждёнными как слепая разметка, — [итоговый отчёт](label_check.md); 10 неизвестных человеку уровней исключены только из метрики уровня, стадии/задачи имеют n=120. Проверяются все 1497 прогнозов и все 120 ID; дубликаты и пропуски отклоняются.

| Поле | Исходные правила accuracy / macro-F1 | Гибрид accuracy / macro-F1 | Принято |
|---|---|---|---|
| Стадии | 0,575 / 0,483 | 0,725 / 0,563 | Правила + LLM только там, где нет правила |
| Уровень (n=110) | 0,582 / 0,395 | 0,736 / 0,376 | Правила; LLM уровня отключена из-за худшего macro-F1 |
| Задачи | 0,475 / 0,355 | 0,525 / 0,417 | Точные исходные метки + классификатор |

Правила и LLM сравниваются на одинаковой области применения, а не по разным когортам: для 77 материалов без стадии у правил accuracy 0,338 / macro-F1 0, у LLM 0,571 / 0,395. На 9 материалах, где добавляется задача классификатора, правила 0 / 0, классификатор 0,667 / 0,489. Для уровня LLM повышает accuracy, но ухудшает macro-F1 всего поля, поэтому не используется. Неизвестные задачи не заполняются выдуманными метками. Проверка 120 материалов использована для выбора источников; это контрольная калибровка, не независимый финальный holdout. Сферы проверены по исходным справочникам, ручных оценок сфер в форме нет.

## Граф и CPU

Векторы float16, 1497×384; semantic_graph — top20 cosine по готовым векторам. behaviour_graph — симметричная нормированная совместная запись на курсы; item_graph — максимум двух матриц. ID/хеши/происхождение в artifacts/ml/manifest.json. Полный поведенческий snapshot не используется в проверке скрытого следующего курса: ранкер читает только semantic_graph; существующие временно корректные course_transitions остаются отдельным признаком. Поиск соседей истории и MMR используют готовые векторы, без повторного кодирования карточек.

Проверены локальная CPU-загрузка (7,72 с), 36 профилей (максимум 0,0553 с без истории), 30 событий истории (0,0639 с), реальный API: health encoder=dense, 1497 карточек, HTTP 200 и пять рекомендаций. Это локальный smoke, не нагрузочный тест. Модель не читает сеть при запуске. Отсутствующие веса в auto включают TF-IDF, повреждённые данные вызывают явную ошибку ранкера/degraded API.

## Воспроизведение

```sh
python -c "from huggingface_hub import snapshot_download; snapshot_download('Qwen/Qwen2.5-7B-Instruct', revision='a09a35458c702b33eeacc393d103063234e8bc28', cache_dir='data/b04/hf', token=False, ignore_patterns=['*.bin'])"
python -m alfarec.pipeline.compare_models --candidate e5-small --handoff data/handoff --output data/b04/models --cache data/b04/hf
python -m alfarec.pipeline.label_catalog --model data/b04/models/e5-small --output data/b04/labels --cache data/b04/hf --llm
python -m alfarec.pipeline.label_catalog --model data/b04/models/e5-small --output data/b04/labels --cache data/b04/hf --level-policy rules
python -m alfarec.eval.label_check score reports/label_check/b04-label-check.json --labels data/b04/labels/item_labels.parquet
python -m alfarec.pipeline.package_ml --model data/b04/models/e5-small --labels data/b04/labels/item_labels.parquet --handoff data/handoff
docker compose up --build
```

Для сравнения повторить команду compare_models с tfidf, tiny, user и e5-base. Ревизии всех четырёх зафиксированы в REVISIONS внутри compare_models; upstream main при повторе не читается. Команда select_encoder на их JSON воспроизводит [решение выбора](b04/selection.json), используя только tune и ограничения ресурсов. Онлайн нужны только загрузки бесплатных весов и библиотек; данные во внешние API не отправляются. Предварительно скачать Qwen указанной ревизии в тот же cache; label_catalog намеренно работает с local_files_only. После сборки Docker содержит безопасные локальные веса; GPU/дамп/ключи сервису не нужны. Переключение ENCODER=auto/tfidf/dense. Поставка производных артефактов не равна слиянию PR; B04 остаётся review до принятия.
