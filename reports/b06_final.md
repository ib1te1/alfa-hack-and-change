# Итог B05/B06: выбранные веса и ручная релевантность

Проверка 16 ноября 2026 года. B05 — PR #38, итог B06 — PR #39. Техническая приёмка завершена; done после принятия соответствующих PR.

## Выбор и доказательства

Зафиксированы 23 варианта. По 22 tune выбран history=0,5 вместо 1,0; остальные веса сохранены, sequence=16 не перенастраивался. На 14 holdout веса не выбирались и после оценки не менялись.

Исторические A399/B361 проверены против своего пакета: 94 общие пары, каппа 1,0. Дополнение A159/B182: 51 общая пара (50 числовых), каппа 1,0, расхождений нет. Сырые файлы сохранены побайтно, подтверждения и производные копии отделены.

Из 3 новых holdout-пар одна оценка B перенесена по точному совпадению карточки и контекста; две оценки B (1 и 1) с обоснованиями получены отдельно. Участнику A в этом дополнении ничего не назначено; его пустой технический файл не считается новыми ручными оценками.

Итоговые веса — [weights.json](../artifacts/weights.json), протокол — [selection.json](../artifacts/weight_tuning/selection.json), числа по каждому профилю и API — [b06_final.json](b06_final.json). Хеши связывают исходники, эксперимент, новые ответы, итоговые оценки и веса.

## Метрики

| Выборка | Вариант | nDCG@10 | Precision@5 | MRR |
|---|---|---|---|---|
| tune, 22 профиля | Начальные веса | 0.555 | 0.364 | 0.480 |
| tune, 22 профиля | Выбранные веса | 0.571 | 0.382 | 0.503 |
| tune, 22 профиля | Бейзлайн | 0.339 | 0.173 | 0.183 |
| holdout, 14 профилей | Начальные веса | 0.507 | 0.271 | 0.393 |
| holdout, 14 профилей | Выбранные веса | 0.499 | 0.257 | 0.333 |
| holdout, 14 профилей | Бейзлайн | 0.250 | 0.043 | 0.054 |

Настройка улучшила tune, но на holdout немного уступила начальным весам. Это зафиксированный результат; выбирать обратно по holdout означало бы нарушить протокол. Превосходство над простым бейзлайном не доказывает рост конверсии.

Нет непросмотренных карточек в итоговых списках. Остались явные unjudgeable: 1 позиция у выбранной системы и 2 у бейзлайна на holdout. По принятому протоколу они исключаются из числовой метрики и показаны отдельно. Выборка мала; исторические профили использовались ранее, поэтому это не новая независимая выборка относительно всей разработки. Исторические и текущие nDCG нельзя сравнивать напрямую: изменился оцениваемый пул. Абляции не измерены.

## Воспроизведение

С локальной моделью принятой B04 и data/handoff:

```sh
python -m alfarec.eval.tune_weights select --answers reports/b06/supplement-9ebd99c2/confirmed-A.json reports/b06/supplement-9ebd99c2/confirmed-B.json --holdout-answers reports/b06/holdout-f09a5163/empty-A.json reports/b06/holdout-f09a5163/derived-B.json
python -m alfarec.eval
```

prepare заново не требуется: исходный эксперимент уже зафиксирован. Перед пересозданием эксперимента надо сохранить исходный пакет и проверить совместимость старых ответов; хеши в ответах не переписываются.
