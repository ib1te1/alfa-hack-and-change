`652a8151…`, формой, инструкцией и проверенными списками из `e6be47b…`.

человеческом заполнении; исходники не исправляются. Применимость уточнённой

считается новой независимой выборкой относительно всей истории разработки.

## Текущий эксперимент

В `artifacts/weight_tuning/experiment.json` фиксируются 23 кандидата, истории,
списки, источники, код, ML-манифест и происхождение переносимых оценок.
Вес sequence не подбирается повторно. Только tune влияет на выбор.

По совпадению всего видимого контекста и публичной карточки перенесены 472 пары.
Нужно дополнить 290 уникальных пар: A159/B182, 51 общая; для tune не хватает
203. Проверенный `select` возвращает код 2 и `missing_tune_judgments`,
победитель null. Итоговый файл выбранных весов не создавался.

Слепая форма содержит только недостающие пары. Все ссылки item → card
проверены. Визуально открыть локальный HTML в доступном встроенном браузере
не удалось: политика браузера запрещает file URL. Внешняя публикация ради
этой проверки не выполнялась; фактическая визуальная проверка этой формы
остаётся не выполнена.

## Проверки

- 421 тест прошёл, 5 пропущены в этой рабочей копии из-за отсутствия дампа
  и локального index_text; полный прогон `tests retrieval_tests`.
- Ruff lint и format пройдены; новые проверки покрывают влияние только tune,
  блокировку всего поиска при пропуске, unjudgeable, фиксированную сетку,
  строгий перенос контекста, хеши и полный цикл holdout-дополнения до весов.
- Независимое ревью выявило и закрыло три дефекта: отсутствие новых карточек
  holdout в форме, неполный список хешируемых входов, неполное происхождение
  дополнительной разметки. Повторное чтение — без обязательных замечаний.
- [Пересчитанный офлайн-отчёт](eval.md) отдельно использует переданные данные;
  он не подменяет ручную оценку dense-выдачи. Ограничения snapshot сохраняются.
