# B10: окончательный запуск

## Границы проверки

Задача продолжает принятые Dockerfile, Compose и режимы B04. Проверяется
итоговая CPU-модель multilingual-e5-small, одна команда запуска без ключей,
работа после сборки без интернета, сохранение событий и явный резерв TF-IDF.
Состав каталога, API и формула ранжирования не меняются.

## Критерии A01

- Свежий клон на второй физической машине без data/, .env и кэшей проекта.
- `docker compose up --build`: страница и рекомендации работают.
- Health сообщает фактический режим dense и 1497 материалов.
- После сборки без интернета сохраняется основной сценарий.
- Обычные события переживают перезапуск; демо-персоны сбрасываются.
- Явный TF-IDF работает и отражается в health.

## Состояние

Подготовка. Физическая вторая машина ещё не проверена. Локальный Docker
и CI не заменяют этот критерий. Результаты фиксируются с SHA и средой;
до получения протокола второй машины B10 остаётся in_progress.
