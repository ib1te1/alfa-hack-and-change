# Исторические независимые оценки B03

Два исходных JSON A/B подтверждены участником команды как настоящие независимые
оценки. Они сохранены без редактирования. К ним восстановлены исходные
`packet-65525fcc.json` и `form-65525fcc.html` из коммита `f7b2ee9`.

Пакет: `65525fcc61942373e067cd138fe858802554343bb20b18891667af2bd34cac18`.
Проверены схема `Response`, независимые коды и подтверждения, пять ответов,
хеш пакета; функция `compare` из текущего `alfarec.eval.calibration` выполнила
сравнение с исходным `Packet`. [Результат](historical-review.md) — техническое
сведение, не завершённый человеческий разбор.

Совпадают пять статусов, в одной паре оба ответа — `unjudgeable`. Исходные
пояснения сохранены в JSON; обсуждение, итог каждой пары, дата и решение по
инструкции ещё нужны. Статус B03 остаётся `review`.

Текущий пакет `f1948269…` отличается: K01–K04 показывают те же поля, K05
заменена с курса «Госзакупки: теория и практика» на глоссарий «Тендер».
Также изменились хеши каталога, инструкции и списка пар. Старый JSON нельзя
выдать за ответ на текущий пакет сменой хеша. Штатный `calibration compare`
проверяет соответствие текущему пакету и потому старые ответы отклонит.

Историческая K05 пересекается с пулом B06. Перед независимой основной оценкой
нужно зафиксировать, обсуждалась ли она, и исключить влияние обсуждённого
примера на оценку по [плану дозакрытия](../../../docs/tasks/CLOSEOUT.md).
