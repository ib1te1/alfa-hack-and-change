# Проверка формы B03 в браузере

Дата: 14 ноября 2026 года. Пакет: `b7d1230829b8e9a6a6a7fffbff37ca1dd0ef0eb2e931fa45550c0331e583fd14`.

Использован локальный Microsoft Edge через Playwright, без сервера и сети: HTML открыт как файл. Проверены окна 1280 × 900 и 390 × 844. Пять пар видны, на узком окне карточки перестраиваются в одну колонку, горизонтальной прокрутки нет. Скриншоты обеих ширин осмотрены; фокус после Tab виден, форма заполняется и экспортирует JSON.

Тестовый экспорт содержал только явно синтетические пояснения и `unjudgeable` для проверки формата. Проверены пять ответов и совпадение хеша пакета с формой; ошибок JavaScript не было. Этот файл не является независимой человеческой оценкой и не добавлен к результатам калибровки.

Полная ручная проверка доступности экранным диктором не выполнялась. Для приёмки B03 остаются две независимые человеческие оценки и разбор расхождений по [инструкции](../docs/calibration.md).
