# Офлайн-оценка: этап 1

Отчёт создаёт `python -m alfarec.eval` по каталогу, индексу B04, ранжированию B05 и входам из `data/handoff/` (см. [отчёт передачи](b02_handoff.md)). Это проверки без ручной разметки. Главная метрика ТЗ — nDCG@10 на тестовых профилях по оценкам 0/1/2 — ещё не посчитана: нужны оценки двух участников. Веса ранжирования ручные, абляций нет.

## Следующий курс по поведению

Пользователей с однозначным последним курсом: 462. Последний по дате курс скрыт, остальные переданы как история; даты точны до месяца, поэтому пользователи с несколькими курсами в последнем месяце исключены.

| Метод | HitRate@5 | MRR |
|---|---|---|
| Наша система (курсы из выдачи, остаток — по популярности) | 0.095 | 0.166 |
| Популярность | 0.779 | 0.260 |

Популярность посчитана по всем записям каталога, включая скрытые; это даёт ей небольшое преимущество, которое не исправлялось.

Наша система здесь проигрывает популярности. При пустом профиле курсы в выдаче подбираются по текстовой близости к пройденным, а популярность весит мало; для следующего курса этого недостаточно. Это задача подбора весов и графа совместных записей (B04, B06), а не исправление под эту метрику.
