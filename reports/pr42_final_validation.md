Linux amd64. Новый удалённый клон указанной ветки на проверенном SHA.
До запуска в нём отсутствовали `data/`, `.env`, каталог модели и Python-окружение.
Ни дамп, ни handoff, ни подготовленные веса из рабочей копии в этот клон не копировались.

Удалены все девять ранее созданных образов этого проекта. Образы, контейнеры и тома
других проектов сохранены. Создан отдельный пустой buildx builder с docker-container driver:
его кеш отсутствовал, поэтому Python, зависимости и модель скачались заново.
В журналах сборки нет использования кешированных шагов. Это более строгая проверка,
чем новый каталог при сохранённых слоях обычного Docker builder.

```powershell
git clone --branch feature/final-deck-history-reason --single-branch https://github.com/ib1te1/alfa-hack-and-change.git jury-clean
cd jury-clean
# Только для проверки отсутствия общего кеша; жюри этот builder не требуется.
$env:BUILDX_BUILDER = 'alfarec-jury-clean-20261116'
docker compose up --build --detach --wait --wait-timeout 180
```

`--detach --wait` только позволяет автоматически зафиксировать готовность вместо удержания
терминала; команда из README `docker compose up --build` использует ту же сборку и сервис.
Получен healthy-контейнер на `127.0.0.1:8000`, `/api/health`:
`status=ok`, `ready=true`, `recommender=ranking`, `encoder=dense`, 1497 материалов.
CPU PyTorch `2.11.0+cpu`, CUDA недоступна и не требуется. Сборка скачала девять
закреплённых файлов E5-small и проверила их контрольные суммы.

## Изоляция, события и резерв

Именно этот образ запущен отдельно с `--network none` и выделенным тестовым томом.
Использована штатная `scripts/docker_probe.py` в фазах seed, restart и smoke:

- dense без сети: стартовая выдача, маршрут, причины, следующий шаг, baseline и восемь персон;
- обычный отзыв исключает материал; после удаления контейнера и создания нового с тем же
  томом отзыв сохраняется;
- отзыв демо-персоны после пересоздания сбрасывается и в постоянный журнал не записывается;
- явный `ENCODER=tfidf` в этом же образе без сети проходит основной сценарий и восемь персон.

Все фазы пройдены; `HostConfig.NetworkMode=none` проверен через Docker inspect.
Тестовые контейнеры и тестовый том удалены. Интернет нужен для первоначальной сборки
и переходов на внешние страницы материалов; рекомендации после сборки работают без него.

## Реальный интерфейс и PDF

В браузере открыт сервис нового клона, а не отдельный сервер разработки.
Проверены холодный старт, выбор маркетинга и сферы услуг, сравнение с baseline,
удаление карточки через «Уже знаю», персона «ИП на маркетплейсах» и видимое объяснение
влияния истории. Запрос вне каталога даёт уточнение и общую подборку.
Ширина 1265 px и узкий экран 390×844: осмотрены карточки и кнопки, горизонтального
обрезания в просмотренных областях нет. Ошибок JavaScript в журнале браузера нет.

`python presentation/build.py` с `ENCODER=dense` создал PDF из 12 страниц 960×540 pt.
Фактический PDF растеризован Poppler; осмотрены все страницы и увеличенные титул,
примеры с историей и метрики. Наложений и обрезаний не обнаружено. На титуле указан
проверенный SHA; примеры получены с моделью. PDF создаётся в `dist/` вне Git.
