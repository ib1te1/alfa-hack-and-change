# Покрытие таксономии на каталоге

Отчёт создаётся командой `python -m alfarec.pipeline.coverage` по `artifacts/catalog.parquet` и `alfarec/recsys/taxonomy.yaml`. Значения сравниваются по нормализованному ключу: регистр, «ё», латинские буквы-двойники.

Материалов в каталоге: 1497. Связь через исходные справочники — слабый сигнал для генерации кандидатов, а не готовая метка задачи: широкие темы относятся к нескольким задачам.

## Ненайденные связи

Нет: каждое значение `source_links` задач встречается в каталоге.
